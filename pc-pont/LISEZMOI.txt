JARVIS - CONTROLE DU PC

1. Double-clique sur Jarvis.bat
   (si Python n'est pas installe, le Microsoft Store s'ouvre : clique sur Obtenir, puis relance Jarvis.bat)
2. Jarvis s'ouvre dans le navigateur. Ouvre-le dans Edge ou Chrome :
   https://matioufnmatiou-cyber.github.io/jarvis/
   En haut a gauche, il doit marquer "PC LIE".
   Si le navigateur demande d'autoriser l'acces aux appareils du reseau local, clique sur Autoriser.
3. Laisse la fenetre noire ouverte (tu peux la reduire).

Exemples :
  "Jarvis, ouvre WhatsApp"        "Jarvis, ferme Discord"
  "Jarvis, ouvre YouTube"         "Jarvis, mets Ninho sur YouTube"
  "Jarvis, monte le son"          "Jarvis, coupe le son"
  "Jarvis, mets pause"            "Jarvis, musique suivante"
  "Jarvis, ouvre mes telechargements"   "Jarvis, fais une capture d'ecran"
  "Jarvis, verrouille le PC"      "Jarvis, eteins le PC" (30 s, "annule l'extinction" pour arreter)
  "Jarvis, ouvre Fortnite" : marche pour toute appli du menu Demarrer.

Pour qu'il demarre tout seul avec Windows : double-clique sur Demarrer-avec-Windows.bat
