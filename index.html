Touchez le réacteur pour me réveiller
Ici le micro est bloqué. Téléchargez Jarvis et ouvrez le fichier dans Chrome ou Edge : là il vous entendra.
Dites « Jarvis » puis votre ordre. Exemples : « Jarvis, mets AC/DC sur YouTube », « Jarvis, quelle heure est-il », « Jarvis, change de voix », « Jarvis, plus grave », « Jarvis, en veille ».

RÉGLAGES

Niveau
Parlez : la barre doit bouger. Choisissez aussi ce micro dans les paramètres du navigateur (edge://settings/content/microphone ou chrome://settings/content/microphone), car c'est celui-là que Jarvis utilise pour comprendre les mots.
Les plus belles voix sont dans Microsoft Edge (voix « Online Natural »).
Facultatif. Laissez l'identifiant vide pour la voix « Daniel ». Pour une autre voix, copiez son « Voice ID » depuis elevenlabs.io.
Facultatif. Sans clé, Jarvis comprend les ordres simples (YouTube, Google, ouvrir un site, l'heure, la date). La clé reste dans votre navigateur.
