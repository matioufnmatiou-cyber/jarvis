# J.A.R.V.I.S.

Assistant vocal façon Jarvis, qu'on commande uniquement à la voix.

- **Version web** : ouvrir le site dans Microsoft Edge ou Chrome, toucher le réacteur, autoriser le micro, puis dire « Jarvis, quelle heure est-il ? ».
- **Version PC** (peut ouvrir des applis) : voir [pc/LISEZMOI.md](pc/LISEZMOI.md).
